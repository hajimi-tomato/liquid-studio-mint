# 界面设计规范

[返回项目首页](../README.md) · [查看实现架构](ARCHITECTURE.md)

## 设计目标

涂抹是一款照片创作工具。界面用阶梯式像素圆角、细格与点阵底纹、克制的光感反馈建立辨识度，同时让照片始终成为视觉主体。默认白色皮肤，另提供绿色、蓝色、紫色、黄色、棕色、橙色和红色。

原则的优先顺序：**功能可用 → 参数含义清楚 → 视觉与动效表达**。示意图不能冒充真实成片，装饰不能遮挡操作，也不能用与功能无关的图片挤占参数空间。

## 信息结构与作用范围

| 区域 | 内容与行为 |
| --- | --- |
| 顶栏 | 品牌、收藏夹、作品库与图片导入；桌面另有快捷操作 |
| 竖向工具栏 | 画笔、调整、玻璃、调色；手机另含导出入口 |
| 参数面板 | 仅呈现所选工具的设置；展开项不改变面板宽度 |
| 中央画布 | 真正编辑、原图 / 上一步对比、缩放与图片切换 |
| 导出面板 | 图片格式与尺寸，或动画样式、时长、预览与生成 |

「下一笔」参数只影响后续笔触。「调整」作用于已有笔触；没有笔触时明确禁用。「玻璃」与「调色」处理当前图片整体。切换工具不会自动替换已有画面。

## 色彩角色

以下是绿色皮肤的参考色。历史 CSS 色值通过 `--skin-c*` 变量接入 `skin-palette.css`；语义变量继续用于新增组件。不要给整个页面或画布套色相滤镜。

| 角色 | 色值 | 当前用途 |
| --- | --- | --- |
| 深绿框架 | `#294A37` | 工具栏与工作台结构 |
| 主操作底色 | `#375F3F` | 主要按钮表面 |
| 正文绿色 | `#2E4E33` | 页面文字 |
| 奶油面板 | `#F8F6E8` | 参数面板渐变起点 |
| 浅绿面板 | `#EAF0DC` | 参数面板渐变终点 |
| 选中状态 | `#D5E6AA` | 选中按钮与分段控件 |
| 边界 | `#AAB99B` | 面板边框 |

悬停、选中、按下和焦点延续当前皮肤谱系，避免出现浏览器默认链接蓝。蓝色皮肤本身允许使用协调的蓝色文字。选中状态还应通过边缘、勾选或 `aria-pressed` 表达，不能只靠颜色。

八套配色以原绿色的 OKLCH 明度与色度层次为基准；超出 sRGB 时降低色度。白色降至近中性，棕色适度压暗并降低色度以与橙色区分。笔刷渐变、高光与投影、品牌像素标记和直方图随皮肤改变；真实照片、玻璃着色小样和导出结果不跟随换肤。选择通过 `liquid-studio-skin` 本地存储键记忆；无有效选择时默认白瓷。

当前文档不声称完成 WCAG 全面审计。基础 token 文件包含暗色变量，但正式入口指定浅色主题，不能将其描述为完整支持暗色模式。

## 字体、字号与间距

使用系统无衬线字体，以 Segoe UI、Microsoft YaHei 和 sans-serif 回退。正式站点无需远程字体请求。

| 内容 | 当前尺度 |
| --- | --- |
| 桌面面板标题 | 16 px |
| 主要按钮与参数标签 | 14 px；紧凑工具区有局部覆盖 |
| 说明文字 | 12 px |
| 手机数值输入 | 16 px |
| 版本与状态栏 | 9–10 px，属于辅助信息 |

以 4 px 为基础组织间距，常用 8 / 12 / 16 / 24 px。面板内边距在桌面通常为 16–18 px，手机为 12 px。基础 token 的字号不一定等于最终组件字号，应同时核对 `pixel-v2.css` 与 `mobile-workspace.css`。

## 组件形态

- **按钮**：使用阶梯切角和像素边缘层次。按下反馈短促，图标与文本保持对齐；禁用状态保留清楚的不可用含义。
- **大面板**：12 px 总切角、4 px 台阶；外围细格、画布点阵和低对比面板细纹分层使用，避免装饰压过照片。
- **滑块**：凹槽轨道、带刻纹的轻拟物滑块；有效区与剩余区清楚分开。手机扩大轨道触控范围，不只扩大图案。
- **数值输入**：显示真实参数；允许直接输入，确认后进入同一套撤销流程。不要做只有视觉变化的假输入框。
- **图标**：24×24 SVG 网格，最终呈现以像素轮廓为主；不要混入 emoji 或依赖系统字体的功能图标。新增图标需检查最终覆盖顺序。
- **展开项**：显示明确的「展开 / 收起」状态与 `aria-expanded`，展开不改变面板宽度。
- **材质预览**：真实玻璃预览读取当前画面；纹理小样主要帮助识别选项。

## 动效与反馈

参数动效应提供可理解的反馈：笔刷大小实时显示直径，光感强度改变波纹强度与速度，动画选项展示方向。笔刷示意和光感波纹都是示意；中央画布才是最终效果。

当前按钮约使用 100–140 ms 的反馈，较长的纹理扫光约 650 ms。尊重 `prefers-reduced-motion`；它不等于禁用用户主动生成的动画作品。

## 响应式布局

- 常规桌面：竖向工具栏、固定宽度参数区、弹性画布与导出区。宽屏参数面板为 264 px，中间宽度区间为 232 px。
- 宽度不超过 780 px：上方保留画布，所选参数或导出面板在下方独立滚动，左侧保留竖向工具栏。
- 宽度不超过 1100 px 且高度不超过 560 px：使用横屏紧凑布局，参数与画布并排。
- 窄屏将真实撤销 / 重做控件移到画布上方，复用同一处理逻辑，不创建另一份编辑状态。

当前手机主要参数按钮最小高度 44 px、滑块触控高度 40 px；画布工具和底部辅助按钮还有更紧凑的尺寸。不要把现状描述为所有控件都达到 44×44 px。

## 样式与图标的实际来源

CSS 按入口文件中的顺序加载：

```text
style → studio → product → design-tokens → refined
      → workspace-v2 → detail-pass → pixel-v2 → mobile-workspace
      → skin-palette → skin-ui
```

基础图标经过 `icon-family.js` 统一，再由 `pixel-v2.js` 对部分图标做像素轮廓覆盖。当前不是单一图标映射表；只改早期文件可能被后面的映射覆盖。

新增设计应先验证真实功能，再检查桌面、手机竖屏、横屏、选中、禁用、键盘焦点和减少动态效果状态。合并历史展示层是后续维护方向，不应在文档中假装已完成。
