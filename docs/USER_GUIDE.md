# 使用指南

[返回项目首页](../README.md)

## 导入与工作区

支持 PNG、JPG 和 WebP，单个文件不超过 60 MiB。可以使用「导入图片」、拖拽、底部加号或「更多图片操作 → 导入文件夹」。文件夹选择能力取决于浏览器。

输入超过 24,000,000 像素，或任一边超过设备 WebGL 纹理上限与 8192 中的较小值时，会先等比缩小并提示。「原图尺寸」导出指当前载入后的图片尺寸；发生缩小后，不会恢复被舍弃的分辨率。

底部图片条切换图片。每张图片保留各自的效果与编辑历史；导入另一张不会自动套用上一张的效果。多选后可以主动套用当前效果，并批量导出 ZIP。

## 画笔与已有涂抹

| 控件 | 作用范围 |
| --- | --- |
| 大小、用量、边缘柔和 | 接下来画出的笔触 |
| 起始纹路 | 后续笔触的纹理，不会自动重画现有笔触 |
| 融合 / 叠放 / 挤压 | 后续涂抹的叠加方式 |
| 调整面板 | 统一修改当前图片上已有笔触的表现 |
| 玻璃、调色 | 当前图片整体画面 |

- **涂抹**：按下并拖动；反复经过会累积涂层。
- **推开**：拖动已有涂层，带动笔刷碰到的笔画。
- **擦除**：选择「单独层擦除」保留下方笔画，或「全部层擦除」露出原图。
- **融合**：连续笔触合成液体区域。
- **叠放**：每次松开完成一笔，保留交叉处的层次。
- **挤压**：新笔触推动邻近液体，形成接触边缘。

没有笔触时，「调整」中依赖已有笔触的参数会禁用；先涂抹或应用预设。

笔刷示意用于查看大小、用量和柔和度，不是最终照片效果。光感波纹也是参数反馈示意；实际结果以中央画布为准。

## 预设、玻璃与调色

「预设收藏夹」包含亚克力 · 芦荟胶、翡翠浅湾、午后温室、雨后长窗和绿野梦游。预览使用当前图片。**应用预设会替换当前涂抹与对应参数，可撤销**。

亚克力预设里的「手动涂抹」只设置后续笔刷，不替换当前玻璃、调色或已画笔触。

玻璃提供透明、海蓝、琥珀、茶棕、酒红五种着色和平滑、长虹、水纹三种表面，以及清透、磨砂、柔光快捷设置。

调色数值可以直接输入。回车或移出输入框确认，Escape 取消；超出范围的数值会限制到有效范围。曝光、对比度和色温范围为 −50～50，饱和度为 −100～100，色相为 −180～180°。

## 保存与恢复

- 「保存作品」保留当前原图、图层和设置，之后从「我的作品」打开。
- 自动草稿保存工作区，存在上次草稿时，可在「我的作品」主动恢复，不会在进站时弹窗打断。
- 两者都使用当前浏览器的 IndexedDB。不同浏览器、设备和网站域名之间不会自动共享数据。
- 清理网站数据、浏览器存储回收或隐私模式退出可能导致本地记录丢失。重要成品请下载保存。
- 当前尚无面向用户的完整工程备份导入 / 导出入口。迁移网站域名之前，需要先考虑旧域名下的作品迁移。

## 导出

| 类型 | 当前选项与边界 |
| --- | --- |
| 图片 | PNG / JPG；当前载入尺寸、长边 1920 或 1080；不放大较小图片 |
| 多图 | 所选图片按当前格式和尺寸逐张导出到 ZIP |
| 预设动画 | 横向流光、纵向流动、柔光呼吸；4 / 6 / 8 秒 |
| 视频 | 使用浏览器 MediaRecorder；支持时优先 MP4，否则 WebM；最高长边 1280，目标 30 fps |
| GIF | 最高长边 640，目标 10 fps；繁忙时可能降帧 |
| 手动录制 | 先准备并确认开始，再调整效果；停止后生成文件 |

MP4 / WebM 是否可选由浏览器能力决定。动画录制只捕获应用画布，不需要相机、麦克风或屏幕共享权限。自动下载被浏览器拦截时，使用结果区的下载入口。

动画预览不修改编辑图层。长动画和大图导出会增加浏览器内存占用；切换后台可能结束录制。推荐先用默认时长验证效果。

## 操作快捷键

| 操作 | 快捷键或手势 |
| --- | --- |
| 撤销 | Ctrl / ⌘ + Z |
| 重做 | Ctrl / ⌘ + Shift + Z；Ctrl / ⌘ + Y |
| 涂抹 / 推开 / 擦除 | B / P / E |
| 拖动画布 | 空格 + 拖动；鼠标中键拖动 |
| 缩放 | 鼠标滚轮或双指手势 |
| 适应画布 | 底部「适应」 |
| 对比原图 / 上一步 | 按住画布上方对应按钮，松开返回 |

输入框内的键盘操作优先用于输入，不切换工具。

## 手机与浏览器兼容性

桌面需启用 WebGL。当前自动化使用 Edge / Chromium，检查了 360×780、390×844、430×932、768×1024、844×390、1024×768、1440×900 等尺寸。

手机竖屏保持画布可见，参数面板独立滚动；横屏采用工具、参数与画布的紧凑布局。触摸涂抹、双指缩放、撤销 / 重做、导入、数值输入、保存、PNG 和 GIF 导出已有自动化验证。

**上述为浏览器触摸模拟结果，不等于实体设备认证。**iPhone Safari、微信内置浏览器、低端手机、大图和长动画仍需真机测试。HEIC、RAW、PSD 等格式当前不在文件导入列表中。
