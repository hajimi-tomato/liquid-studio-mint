# 涂抹 · Liquid Studio

淡绿色三栏图片工作台。纯静态、客户端 WebGL 图像处理；照片不上传服务器。

## 第一版

- PNG/JPG/WebP 文件选择、拖拽上传；初始演示图片。
- 透明液体涂抹、推开、擦除；笔刷大小、厚度、边缘柔和。
- 空白、薄涂、手作纹路三个液体初始状态。
- 清透、凝胶、流光三种液体质感，支持折射力度、边缘光泽、柔光扩散调节。
- 最近 25 次涂抹操作撤销和重做；清空可撤销。
- 亮度、对比度、色相、饱和度、色温；完整实时小预览。
- 原图对比、滚轮/双指缩放、空格拖动画布。
- PNG/JPG 导出，原图或指定长边尺寸。超过 24MP 或最大纹理边长的输入会缩小并提示。

## 实现

`dist/app.js` 中的笔刷维护液体厚度和方向场。WebGL 片元着色器按高度梯度进行局部折射，结合方向模糊、轻微色散和边缘光照。推开工具搬运现有的涂层数据。它是用于交互图片创作的近似效果，不是流体物理模拟，也未声称精确复现参考视频。

`dist` 是完整静态站点入口，可通过任意静态 HTTP 服务器运行。无构建依赖。

示例照片由 OpenAI 内置图像生成工具生成：白色波斯菊、玻璃花瓶、窗边阳光、灰绿色背景，无滤镜。
