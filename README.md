# 涂抹 · Liquid Studio

墨绿画布与浅色工具区的图片工作台，采用已确认的交互 Demo 样式。纯静态、客户端 WebGL 图像处理；照片不上传服务器。

## 在线使用

**[打开新版工作台 · 在线体验 →版本 2026.09.20.3](https://hajimi-tomato.github.io/liquid-studio-mint/studio-20260920-3.html)**

页面左下角显示 `v2026.09.20.3`。本次使用独立版本入口，便于确认加载的版本。

无需安装，直接打开链接即可使用，也可以分享给朋友。这个在线入口对应正式网站，已采用与交互 Demo 一致的工作台布局，接入真实图片处理和下载。

- 左侧工具栏：画笔、效果、玻璃、调色。
- 中间：真实编辑画布、图片切换、按住对比原图 / 上一步、去除所有修改（可撤销）与缩放；更多操作位于底栏「···」。
- 右侧：图片 / 动画导出，动画方向卡片、时长选择、播放预览及生成下载。
- 手机：上方保留画布，左下工具栏切换当前面板或导出。

最新版已包含 [PR #1](https://github.com/hajimi-tomato/liquid-studio-mint/pull/1) 的独立叠放、挤压涂抹与分层擦除。体验路径：左侧选择「画笔」→「叠加方式」→ 选择「叠放」或「挤压」；选择「擦除」后可切换「单独层擦除 / 全部层擦除」。

网站与主分支通过下方发布步骤同步；合并 PR 后需要重新发布才能在线体验。若仍看到旧界面，请按 Ctrl + F5（Mac：Cmd + Shift + R）刷新。

## 更新 GitHub Pages

源码位于 `main` 分支，公开网站从 `gh-pages` 分支发布。修改 `dist` 并提交后，运行：

```sh
git push github main
git subtree push --prefix dist github gh-pages
```

这里的 `github` 是指向本 GitHub 仓库的 Git remote；若克隆后的 remote 名为 `origin`，请相应替换。

## 第一版

- 多选图片或导入文件夹，在画布下方的图片工作区切换。每张图片独立保留涂抹、玻璃、调色和撤销/重做记录；工作区仅在当前会话有效，刷新前请将需要保留的作品存为预设。
- 材质初始状态采用独立悬浮预览，支持键盘聚焦与 Escape 关闭；悬浮或聚焦只在独立浮窗预览；点击选中后用于下一笔涂抹，不改动已有画面。选中状态随作品和预设保留。现有空白、薄涂、手作纹路、水波、旋涡、凝露、流淌 7 种示意。
- 绿色、非衬线字体、以直角为主的三栏工作台，兼容窄屏。

- 右侧「动画」默认采用预设动画：横向流光、纵向流动、柔光呼吸，可选择 4/6/8 秒循环，独立预览后生成并自动发起下载。动画冻结当前图片与编辑参数，联动折射、厚度、光泽和柔化，不改写作品。
- 推荐依据本地 64×64 明暗方差与纹理梯度，不上传图片，也不进行人物/风景等语义识别。可手动改选，切换导出 Tab 保留选择。
- 手动录制先进入准备状态，再次点击「确认开始」（Esc 取消），停止后自动发起下载，并保留下载入口。
- 预设 GIF 按固定帧时间离线渲染；预设视频使用浏览器 MediaRecorder，生成仍需约所选动画时长，实际速度受设备影响。浏览器若阻止自动下载，可点击结果下的下载按钮。
- 视频最高长边 1280 / 30fps，GIF 640 / 10fps（繁忙时自适应降帧并保留时间间隔）；不设固定时长上限，录制文件占用浏览器内存，长录制推荐视频。切换后台会自动结束并生成文件。
- GIF 编码在 Web Worker 中进行，使用本地随附的 [gifenc 1.0.3](https://github.com/mattdesl/gifenc)，MIT 许可证见 `dist/vendor/gifenc.LICENSE`。录制无需相机、麦克风或屏幕共享权限。

- PNG/JPG/WebP 文件选择、拖拽上传；初始演示图片。
- 透明液体涂抹、推开、擦除；笔刷大小、厚度、边缘柔和。
- 空白、薄涂、手作纹路三个液体初始状态。
- 清透、凝胶、流光三种液体质感，支持折射力度、边缘光泽、柔光扩散调节。
- 当前涂抹层可统一调整整体强度、成像厚度和画面柔化；这些参数会同时影响局部折射、方向拖影、失焦、反差压低、乳白透光和高光晕染。
- 最近 25 次涂抹操作撤销和重做；清空可撤销。
- 亮度、对比度、色相、饱和度、色温；完整实时小预览。
- 原图对比与上一步修改对比（按住查看、松开返回，不修改历史）；滚轮/双指缩放、空格拖动画布。
- PNG/JPG 导出，原图或指定长边尺寸。超过 24MP 或最大纹理边长的输入会缩小并提示。

- 涂抹模式：**融合**（默认）让连续笔画像液体一样汇成一片；**独立叠放**把每次按下到松开当作一笔，后画的叠在上面，交叉处保留各自边缘；**挤压**让新笔画像气泡一样把邻近液体挤开，贴近处形成平直接触边。切换只影响之后的笔画。选中擦除工具时显示擦除模式：**单独层擦除**只作用于最先碰到的上层笔画，不会擦穿下方；**全部层擦除**擦掉笔刷碰到的所有层。推开会带动笔刷碰到的所有层一起移动。
- 预设记录升级为 v2（逐层保存）；旧版 v1 预设仍可打开，会作为一个融合层恢复。

## 开发验证

运行时零依赖。`npm test` 运行数据层与渲染器的 Node 单元测试；`npm run test:e2e` 使用 Playwright 在真实浏览器里验证交叉笔画与擦除行为（需先 `npm install`）。

## 实现

`dist/stroke-layers.js` 维护有序的笔画图层文档（每层裁剪后的厚度与方向场，已提交层不可变）；`dist/liquid-renderer.js` 先绘制玻璃底图，再自下而上逐层折射合成（两张离屏纹理交替读写），最后统一调色。`dist/app.js` 负责手势、历史、工作区、预设与导出。WebGL 片元着色器按高度梯度进行局部折射，结合方向模糊、色散、局部失焦、反差软化、乳白透光、边缘光泽和亮部晕染，模拟洗手液在玻璃或照片表面的成像变化。推开工具搬运所选图层的涂层数据。它是用于交互图片创作的近似效果，不是流体物理模拟，也未声称精确复现参考视频。

`dist` 是完整静态站点入口，可通过任意静态 HTTP 服务器运行。无构建依赖。

示例照片由 OpenAI 内置图像生成工具生成：白色波斯菊、玻璃花瓶、窗边阳光、灰绿色背景，无滤镜。
